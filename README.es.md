# Aura Zero

Aura Zero es el operador de IA de Reveta, centrado en la voz.

This repository is Aura Zero, Reveta's voice-first AI operator, built on Hermes Agent by Nous Research (MIT). The current README is in English: [README.md](README.md).

The upstream Hermes Agent README in this language is available at <https://github.com/NousResearch/hermes-agent/blob/main/README.es.md>.
