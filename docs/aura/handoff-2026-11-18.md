## 4. Findings

1. **Persistence** (`docs/aura/persistence-options.md`, sources are vendor pages):
   - Render free wipes the filesystem on every 15-minute idle spin-down, not only on redeploys.
   - Persistent disks are paid-only.
   - Supabase Free: 1 GB storage, 5 GB egress a month, 50 MB per object, no object versioning; it pauses after 7 days without *database* activity.
   - Option B needs no changes to forbidden files for persistence (`/opt/data` is already the image's volume).
   - Oracle Always Free: 2 OCPU / 12 GB Arm, 200 GB block storage. It reclaims instances that stay under 20% on CPU, network and memory for 7 days.
2. **`scripts/reveta/aura_config.py --write` resets owner settings on every boot.**
   - Lines ~205–220: `config.update(settings)` replaces the whole `aura` block and `platform_toolsets`; only `aura.paid_route` and `model` are carried over.
   - Effect: #17's Tools switches, `aura.clarify_without_approval` and `aura.voice.full_duplex` are lost on every restart, even on a persistent disk.
   - It runs in the Render start command: `aura_config.py --write "$HERMES_HOME/config.yaml" && exec entrypoint-dispatch.sh gateway run` (`docs/aura/HANDOFF.md`).
3. **Hard-coded public address.** `aura_config.py` sets `webapp.public_url: https://aura-zero.onrender.com`, which feeds the webapp's Origin checks. A new host (decision E) needs it configurable (decision D).
4. **Pipecat memory** (PR #16's measurement, not re-measured here):
   - The speech process tree peaked at **~273 MiB RSS** (PR #11: 249 MiB), plus 524 MB of disk.
   - Render free allows **512 MiB** and the server already used about 479 MiB.
   - Full duplex cannot run on Render free; it needs a host with more memory (Oracle A1 with 12 GB fits on paper; unverified) or a separate speech host.
5. **ffmpeg/Flite silent-speech risk** (PR #16):
   - The PM-managed ffmpeg (`~/.hermes/tools/ffmpeg-9.0.1`) has no `flite` filter, and Debian `/usr/bin/ffmpeg` does.
   - `voice_mode()` checks only that ffmpeg exists, so with PM ffmpeg first on the path, full duplex would start and stay silent.
   - Fix: probe for the `flite` filter (`ffmpeg -filters`) and report unavailable, so the UI falls back to browser voice.
6. **Clarify approval:** with the gate unchanged, a clarifying question needs one approval tap before it appears (browser capabilities scenario).
7. **Full browser needs terminal:** Hermes offers `browser_exec` only alongside the terminal surface (`model_tools._rewrite_browser_exec`). #17 enforces "Full browser" requiring "Commands".
